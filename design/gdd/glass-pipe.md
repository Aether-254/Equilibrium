## Overview

GlassPipe is the first fluid carrier. Each pipe cell stores contents that may include liquid and gas at once, described by a component list (`SubstanceId`, amount, phase contribution), temperature, pressure, and liquid/gas volumes. Pipes connect through explicit adjacency edges that blockers can disable; a crossing bridge has two independent channels. Visually, liquid and gas layers each use the same full internal mask (top-down view), gas drawn over liquid; components within a phase split the layer into equal-area regions in stable order with alpha encoding remaining amount. The visual layer only reads simulation data. Alpha implements a simplified flow model; the data and save schema must already express immiscible layering, partial miscibility, immediate and conditional reactions.

## Player Fantasy

Direct. Seeing two colored liquids share a pipe run, watching a gas layer creep over them, and closing a side with a blocker to stop a mix are visceral chemistry moments. The fantasy is seeing matter behave, which is what Tier 3-4 will monetize.

## Detailed Design

### Core Rules

**Content model (binding from Alpha)**
1. Pipe cell contents: `components[]` where each component has `SubstanceId`, `amount` (mol or kg, unit fixed per substance def), and phase contribution (liquid/gas fraction); plus `temperature`, `pressure`, `liquidVolume`, `gasVolume`.
2. Whether liquid and gas coexist and how they distribute is decided by simulation (gravity, flow, surface tension, and other applicable physics in later tiers); the schema MUST NOT encode "single phase per cell" as a permanent constraint.
3. The same structure must extend to fully miscible, partially miscible, immiscible layered, immediately reacting, and condition-triggered reacting mixtures. Alpha content uses few substances and simple conditions.
4. Saves persist the full component list; visuals persist nothing.

**Connectivity**
5. Pipes connect to adjacent pipes and fluid Ports via explicit edges (grid-world). Blockers disable the ingress edge for that side regardless of phase (flow-blocker rule 5).
6. Crossing bridge: horizontal and vertical channels are independent in routing and content; occupying one cell does not merge them.
7. Blockers on pipes are not filters (no per-phase or per-substance blocking).

**Alpha flow model (simplified)**
8. Per tick, each connected pipe network equalizes pressure by moving volume from higher to lower pressure cells along enabled edges, limited by a per-edge conductance; liquid and gas are moved as separate volumes; no reactions unless a substance pair is flagged `immediateReaction` in content (then products replace reactants on contact).
9. Pipe capacity per cell is `pipeVolume`; exceeding it is impossible (transactions reject).

**Visual (binding)**
10. Top-down view. Liquid layer and gas layer both use the full internal mask of the cell's topology; equal covered area; liquid drawn first, gas over it (physical covering order, not screen-up/down).
11. Within a phase, colored components divide the layer into equal-area regions regardless of amount; each region's alpha is a linear normalization of remaining amount, clamped; minimum visible nonzero alpha TBD.
12. Component order within a phase is stable (default: `SubstanceId` order) so regions never swap per tick.
13. Regions and alpha are generated by mask + shader/material parameters; no per-fill-level texture frames.
14. Direction shorthand uses the observer's screen orientation; `r` means left-to-right.
15. Missing topology textures/masks are drawn by the creator; no placeholder art is generated or treated as final.

### States and Transitions

None beyond contents; a cell is Empty or Holding(components).

## Formulas

The equalization step (Alpha) is defined as:

`ΔV_ab = clamp(k_ab * (P_a − P_b), −V_a_phase, V_b_free)` per phase per enabled edge

**Variables:**
| Variable | Symbol | Type | Range | Description |
|---|---|---|---|---|
| conductance | k_ab | float | 0..1 | per edge per tick |
| pressures | P_a, P_b | float | >= 0 | cell pressures |
| available volume | V_a_phase | float | >= 0 | phase volume in a |
| free volume | V_b_free | float | >= 0 | pipeVolume − used in b |

**Output Range:** signed volume moved; conservation holds per substance.
**Example:** k = 0.5, P_a = 2, P_b = 1, plenty of room: 0.5 volume from a to b.

The region alpha formula is defined as:

`alpha_i = clamp(amount_i / amountRef_i, alphaMin, 1)` for visible components; `0` when `amount_i = 0`

**Variables:**
| Variable | Symbol | Type | Range | Description |
|---|---|---|---|---|
| amount | amount_i | float | >= 0 | component amount in the cell |
| reference | amountRef_i | float | > 0 | amount that saturates alpha (per substance) |
| minimum | alphaMin | float | 0.05..0.3 | TBD |

**Example:** amount 0.2 of ref 1.0, alphaMin 0.1: alpha 0.2.

The region partition rule is defined as:

`area_i = maskArea / n_phase` for each of the `n_phase` colored components in that phase, in stable order.

## Edge Cases

- **If a cell has liquid only**: gas layer is fully transparent; liquid layer draws.
- **If two components have identical `SubstanceId`**: merged into one component (amounts add).
- **If a substance has no color**: it occupies no visual region but exists in data.
- **If a blocker is placed where gas is currently flowing in**: this tick's committed move stands; blocked from next tick.
- **If pressure would exceed a defined maximum**: Alpha clamps and logs `PipeOverpressure`; rupture is Tier 4.
- **If a bridge cell receives from both channels**: each channel handles its own contents; no mixing.
- **If a save contains a component with a phase fraction outside [0,1]**: clamp with warning; never fail load.
- **If temperature/pressure fields are missing in an old save**: default to ambient constants.
- **If topology mask is missing**: draw nothing for contents and show a missing-asset marker (rule 15).

## Visual/Audio Requirements

Per spec s7.9 and s20: 32 x 32 Point-filtered PNG topology textures and masks; two masks for the bridge; shader-driven regions and alpha; canonical orientation rotated at runtime. Liquid gurgle and gas hiss cues (Tier 4).

## UI Requirements

Inspection shows components with phase, amount, T, P; blocker status per side; bridge shows both channels.

## Acceptance Criteria

- **GIVEN** a cell with liquid A and gas B, **WHEN** rendered, **THEN** the liquid layer covers the full mask and the gas layer covers the same full mask above it.
- **GIVEN** liquid components A and B in one cell, **WHEN** rendered, **THEN** each occupies half the liquid layer regardless of amounts, in SubstanceId order, with alpha proportional to amount.
- **GIVEN** amounts change over ticks, **WHEN** rendered, **THEN** region positions never swap.
- **GIVEN** a blocker on a pipe's N side, **WHEN** the N neighbor has higher pressure, **THEN** no volume enters from N.
- **GIVEN** a bridge with water in the horizontal channel and gas in the vertical, **WHEN** ticked, **THEN** channels remain separate.
- **GIVEN** two connected cells at P 2 and 1 with k 0.5, **WHEN** ticked, **THEN** 0.5 volume moves and total substance is conserved.
- **GIVEN** a save from Alpha, **WHEN** loaded in a Tier 4 build with reaction support, **THEN** the component list loads without migration errors.
- **GIVEN** a missing topology mask, **WHEN** rendered, **THEN** a missing-asset marker is shown and no generated placeholder art appears.
